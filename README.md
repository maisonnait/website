# Maison N'Ait — website

One-page brand site for Maison N'Ait (Moroccan perfume house): the story of the name, five notes of Morocco, a 26-second film, the catalogue and how to order. Four languages: Darija, Arabic, French, English (right-to-left handled).

## What is here

- `index.html` — the whole site in one file (styles, scripts and text inlined).
- `media/` — the three videos and their poster images. Keep this folder next to `index.html`.
- `source/` — the editable parts and the build script.

## Run it

It is a static site: open `index.html`, or serve the folder with any static host.
On GitHub Pages: Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`.

A link can open in a given language: add `#fr`, `#en`, `#ar` or `#darija` to the address.

## Change it

Edit the files in `source/`, then rebuild:

    python3 source/build.py

- `i18n.json` — every text, per language (`fr`, `en`, `ar`, `ary` = Darija). The build stops if a key is missing in one language.
- `catalog.json` — collections, scent families and scents, copied from maisonait.youcan.store on 13 Nov 2026. Each "Order" button opens the matching product page of the shop.
- `page.html`, `styles.css`, `app.js` — structure, look and behaviour.
- `sketches.js` — the five canvas drawings of the notes.
- `glyphs.json` — outlines of the wordmark and of the Tifinagh letters.

## Notes

- Fonts load from Google Fonts (Josefin Sans, Spectral, Reem Kufi, Tajawal, Noto Naskh Arabic).
- The videos are generated by code, not filmed. Product photos and the shop logo are not included yet; each family shows a drawn flacon.
- The brand story and the Arabic name «دار نايت» are a proposal to validate.
